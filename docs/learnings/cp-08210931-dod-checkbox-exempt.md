# Learning: 不可变文档要区分「内容」与「状态」两种字节（第五层）

### 根本原因
- contract-dod.md 进封印集（r31 修复的正确决定）后，其 checkbox 完成状态被一并冻结；
  而 CI 门禁（dod-format-check）要求实现后全勾——两个都对的规则夹死 fix。
- 深层：DoD 文档承载两类信息——**验收条目（合同内容，不可变）**与**完成状态（实现
  进度，必须可变）**。封印按字节整体比对，无法区分。

### 下次预防
- 把文件纳入不可变集前，问「这文件里有没有生命周期字段」；有则为其定义精确的
  允许变换（如本修：同行 `- [ ]`→`- [x]`），而不是整体豁免或整体冻结。
- 洋葱修复期（连修五层）的规律：每个新闸上线后，跑一轮真实 run 让 fix 把所有
  「它必须做的动作」暴露一遍，闸与动作的冲突只有真跑才现形——容器日志捕捉器
  （catch-all-fleet.sh）是这类冲突的唯一一手证据来源。
