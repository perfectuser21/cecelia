# Learning: 守卫补链刀——七机制第5号(生存)闭合

### 根本原因
harness 执行体(容器)是"半失控"级,但守卫全押在写码质量层:zombie-reaper 对 harness_* 全豁免、callback 只 ack 不校验任务终态、phase-event 心跳从未真 fire——07-18 夜两容器退出后任务孤儿化 2.5h 无人收。守卫密度与失控程度不匹配。

### 下次预防
- [ ] 失控程度越高守卫越重:容器级执行体必须有"退出即校验任务终态"的机械链(callback 一致性闸),不许只靠会话自觉收尾
- [ ] 任何"豁免"必须配替代守卫:reaper 豁免 harness 的同时就该建专属守护,豁免+无替代=裸奔
- [ ] 靠提示词禁止的行为(等 Monitor 自杀)必须配机械检测计数,措辞病是模型行为家族,提示词治不住
- [ ] 共享基础设施(主仓)必须有状态哨兵:cron 全家住在主仓,主仓歪=全歪且静默
