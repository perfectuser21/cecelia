# Learning：秋米派活链路四处静默故障（任务 7951bd36）

### 根本原因

- 采集器读的配置文件已被上游改名废弃（`clawdbot.json` 停在 09-21），读旧文件不报错，只是新 agent 永远进不了名册——**读到旧数据比读不到更难发现**。
- 会话键用 task_id，重排后 agent 在同一会话里看见上一轮结果，直接复述交卷，0 次工具调用。
- 回执解析假设输出是单行 JSON，真实输出是多行缩进且被 `tail -c` 截在中间，`text` 恒为空，没人发现。
- 两个 Notion 投影模块共用 `tasks.notion_id` 一列，互相覆盖。
- 桥接器只发 SIGTERM 且只在子进程 close 时回话；`claude -p` 无视 SIGTERM，进程与调用方同时挂死。

### 下次预防

- [ ] 执行会话键一律带本次运行 id，不复用

- [ ] 一列只能有一个写入方；新增投影时先查谁还在写同一列
- [ ] 子进程超时一律「SIGTERM → 宽限 → SIGKILL」，且超时当下就回话
