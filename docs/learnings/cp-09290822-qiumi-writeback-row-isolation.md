# 秋米回写单行失败挡住整步（09-29）

### 根本原因
- pushQiumiStatus 逐行 await，任一行抛错就中止整个回写步骤；排在它后面的行本轮全都推不上去，下一轮又从同一行开始，永久卡死。
- 上一版（#5646）只补了「中文页已归档」一种永久失败；部署后马上又被一张被彻底删除的页（GET 404）卡住，十余条已完成任务在中文表停在「排队」。修症状而不是修结构，同类问题换个形态立刻复发。

### 下次预防
- [ ] 批量同步循环一律每行 try/catch：永久失败记指纹跳过，临时失败留到下轮，本轮其余行照常处理，末尾汇总报错
- [ ] 修完部署后要看「积压集合是否真的在下降」，不能只看报错是否消失
