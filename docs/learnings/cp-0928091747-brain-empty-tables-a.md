## 大脑库 76 张空表：迁移只建不删（2026-09-28）

### 根本原因
- 迁移文件只增不减：删表要单独写迁移还要冒风险，Harness 六代每代加一组新表、旧的一组原地留着；从来没有「这张表有没有写入方」的检查。
- 09-10 大迁移整库搬运，把仓库历史里找不到建表记录的更早残留一起带进了生产（36 张空表在 brain 迁移里无 CREATE TABLE）。
- 拆库前 ZenithJoy 与大脑共用一个库，拆库后大脑侧留下空副本（licenses 等），真账在 hk zenithjoy。
- 「只读不写」的空表会让功能静默失效：读的一半接上了、写的一半没做或被删，页面永远读到空。
