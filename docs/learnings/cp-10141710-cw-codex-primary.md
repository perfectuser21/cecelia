## Codex 常驻迁移（2026-10-14）

### 根本原因

单次原生 Codex 本地 QA 成功不证明常驻链能接管。安装器仍强依赖 Claude 且不固化账号，预览 QA 被适配器明确拒绝，独立裁判另依赖 API；心跳产物又使旧启动器持续拒绝自更新。

### 下次预防

- [x] 安装与运行校验同一执行用户、CLI、订阅账号和角色模型；失败不回退其他身份。
- [x] 原生裁判完整输入走 stdin，最终答复须与原生事件对应；不完整会话、工具调用及额度错误不算通过。
- [x] 预览访问能力由控制器绑定实际 SHA，经单个 Unix socket 转发，不能靠 prompt 或域名白名单放开整台主机。
- [ ] 常驻切换必须额外取得真实服务调度回执；不能拿有头候选探针冒充部署完成。
