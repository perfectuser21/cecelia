## 固定 Skill 的 CI 冷缓存与历史来源（2026-10-19）

### 根本原因

正式 CI 是空环境，固定业务锁并不自动带来中央仓 Git 对象或未跟踪的生成 Skill 文件。快照引用的历史 Activity 还可能使用不同业务锁，不能只准备 base/head。官方单范围 artifact 使用 snapshot 包装，而缓存入口消费 canonical snapshot；仅测试裸 JSON 不能证明真实工作流链已接通。
