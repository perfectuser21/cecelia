# Gate3 假红——断言不带等待预算（2026-07-15）

## 根本原因

Gate3 部署链墙钟 ~7min（镜像 build + drain 120s + canary smoke + sidecar swap），但 workflow 等待步只轮询 300s，随后 assert-deploy-effect 一锤子判定。其第 3 参 900 是 max_uptime_s（容器新鲜度阈值），名字里带数字预算感、实际不是等待预算——调用方误以为它会等。结果：部署真成功、GHA 必假红，每次 brain 合并误报一次。

## 下次预防

- [ ] 异步动作的效果断言必须自带等待预算（轮询到成功或超时），禁止"上游等待步 + 下游一锤断言"拼接——两步之间的时间差就是假红窗口
- [ ] 脚本位置参数超过 2 个时用法注释必须逐参写清语义（900 被误读为等待预算即教训）
- [ ] 改判定类脚本时，verdict 文案与退出码是对外契约，收敛重构须逐字保持（本次 check_once 收敛由既有 5 case 回归闸看住）
