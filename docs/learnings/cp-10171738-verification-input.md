# 已认领测试的直接静态输入来源

本棒仅修复辅助来源证明；不把测试输入依赖当成 CLI、模型或业务执行成功。

实际缺口：普通 verification 角色只接测试/冒烟等既有类型，无法给 .mjs 夹具合法归属。新增 verification_input 只接受固定 Git 常规 __tests__/fixtures/*.mjs、已原生认领的测试、唯一直接顶层静态 ESM 导入；完整 owner 源文散列和导入范围重解析，虚假原生身份及证据篡改拒绝。

调用接缝：真实来源入口对 base/head 查询 owner 并集。仅另一侧声明的测试查询行不应被当成当前侧归属；某个 scope 完全未认领时保留 UNKNOWN 和缺口，不伪造覆盖，也不抢先中断另一 scope 的实际联合证明。非空匹配与原生身份不一致仍拒绝。

实际测试：先提交红测，再实现。新增 43 项专项用例通过；注册的 auxiliary assertion 完整 132 项通过，原 483 行断言正文保留，仅增加静态导入新回归。source 文件用 Brain ESLint 配置检查存在两个与 a444 原文相同的历史 no-useless-escape，未称全 lint 绿。固定 Git 完整双 scope 集成、正式 CI 和新任务验收另看对应真实运行证据，本文不预认完成。
