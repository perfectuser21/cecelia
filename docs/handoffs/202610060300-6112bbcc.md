## 教训

- 守卫扫描范围要覆盖所有会跑 SQL 的目录（漏了 `packages/brain/scripts/`，CI 才在 CLI pr 模式报 `42P01`）。
- 旧迁移重放期间外键引用旧名，视图会报 `referenced relation is not a table`：夹具用 `withLegacyNames` 包住重放。
- 注册表键、页面链接实体类型（`projection_links.entity_type`）、`LEGACY_DB_CONSTANTS` 三处都按表名存，改名要一起迁，否则目录投影判「页面被占用」。
- 带 `notion_id` 列的表/视图/备份表都要在注册表有登记，备份表不要带 `notion_*` 列。
- 新增非测试源文件，测试要放同目录或同目录的 `__tests__`（lint-test-pairing）。
- 几个 PR 同时在顶部加说明条目会反复冲突：用 merge 同步 main，一次解完，两边都留。
- CodeQL 会抓回溯正则：解析 frontmatter 这类用字符串扫描。
