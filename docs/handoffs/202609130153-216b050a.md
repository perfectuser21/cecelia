
`scripts/brain-deploy.sh` 第 17 行就是 `VERSION=$(node -e ...)`，全脚本用了 **15 处** node；

> 没有顺手装 node 的原因：`brain-deploy.sh` 在这台机器上是**完全未验证**路径（脚本里还带 macOS

**为什么影子方案不成立（两个独立原因，任一都足以否掉它）：**

- **假绿**：compose 里 `BRAIN_PORT=5221` 与 healthcheck 的 `curl http://localhost:5221/...` **都是硬编码**

  `BRAIN_PORT`，healthcheck 里的 `localhost:5221` 打到的仍是**主容器**——影子永远"健康"，验了个寂寞。
  要做影子必须同时 override `BRAIN_PORT` 和整个 `healthcheck` 块。
- **挡不住写**：`CECELIA_TICK_ENABLED=false` 只关 tick，**关不掉 startup-sync**——它在 boot 就跑，会
  re-queue 任务（`executor.js:4588` `[startup-sync] LangGraph task re-queued`、`:4639` `Inline task requeued`）。
  影子容器连生产库 = 和主容器**双重 re-queue**，比不做影子更危险。

  故本次改用「一次性容器验证镜像 + 直接切换」：验证不连库做写操作，切换那一下的重启本来就要付
  re-queue 的代价，付一次即可。
