## 完成

- 三工具适配器 `conversation-capture-{claude,codex,grok}.js`，按 `session_id` 分组；Codex/Grok 用官方"纯人类输入"专用日志（`history.jsonl`/`prompt_history.jsonl`），无需像 Claude Code 那样过滤 role
- 编排层重写：15 分钟闲置判定替代逐条消息轮询，原始文本 + Haiku 生成 2-4 条 topic 摘要各写一条 capture
- `source` 按工具区分 `conversation-claude`/`conversation-codex`/`conversation-grok`（migration 356 改名历史行），`VALID_NATURES` 加 `session_summary`
- 修复终审抓出的 2 个 Critical：① mtime 增量扫描窗口与 15 分钟闲置阈值时间常数互斥，导致会话在默认配置下几乎永远不会被捕获（改为固定 35 分钟回看窗口）② LLM 摘要调用无前置去重检查，扩大扫描窗口后会对已处理 session 重复计费（加 `dedupe_key` 存在性检查，fail-open）
- 修复 2 个 Important：适配器异常未计入 `errors`（已加 `adapter_failures` 字段）+ 前端 `GTDInbox.tsx` 硬编码旧 `source` 值导致徽标失效（改前缀匹配 + 三工具区分标签）
- 只抓 Brain 所在美国本机文件，不做跨机同步（避免误抓同事在西安机器上的交互内容）
- 45+ 测试全绿，3 轮 Task 级 review + 1 轮跨任务综合终审（抓出上述 Critical），PR #4138 已合并
