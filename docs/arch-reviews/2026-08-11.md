- 上一轮基线后合入 18 个 PR，`packages/brain/src` 非测试 JS 增至 616；全仓相关变更约 `+10543/-248`，主要增长来自 Universal Map 与 Kernel 修复。

- guard-drill 的 Bark 有 dedupe，Issue 没有 dedupe；同一失败在每个进程首次调度时都创建新 P1，告警通道与治理台账语义不一致。

- registry 刷新和 production/staging 同 SHA 是本轮真实改善；它们不覆盖时间、review 身份、环境副作用和生产 schema 正本风险。
