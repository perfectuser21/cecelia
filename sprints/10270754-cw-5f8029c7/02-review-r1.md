场景: QA 按 Q-1 在临时 Git 仓库提交四类正文和薄索引后，用该仓库运行 new-task；CLI 因仓库未登记而拒绝建单，即使预先登记仓库，临时索引也没有独立可信锚，正常引用得不到 found，Q-2 的历史版本回放也无法验收。

说明: 明确可在预览环境实际执行的受控仓库登记和可信索引锚定方式，以及 Q-1/Q-2 使用的具体计划字段与命令；锚必须先于任务独立建立，不能以任务自行提交的索引给自己授权。保留临时真实 Git 仓库的黑盒验收，不以测试内部断言替代。
